# What is this?
- A pack that contains all the Pokemon I've done for videos.
- Everything I mention here has a toggle.
- Packaging them together reduces bloat, and I value that a lot.
- If you are here for Coalossal, for example, go to my page and check the individual Coalossal page for the details of that Pokemon.
- Right now, we have 3 Pokemon. More will be added. Check the latest releases to see the additions.

# Other features:
- This also adds the new types (Steel, Dark, Fairy).
- I did use a more modern Steel type chart so it isn't so overpowered (ironic).
- Toggle to fix Psychic being immune to Ghost so we can run some cool ghost Pokemon.
- You can toggle the new types, the ghost fix, and each individual Pokemon.

# Disclaimer:
-If you turn one option off but leave another on, there might be some conflicts. For example, if I add a dark type Pokemon and you turn new types off, it will probably just break (I haven't tested it).
